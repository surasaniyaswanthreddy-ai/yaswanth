# Customer Behavior Analysis

## Project Overview
This project analyzes customer behavior using SQL and Power BI to uncover purchasing trends and generate actionable business insights.

## Tools Used
- SQL (MySQL)
- Power BI
- Python (Jupyter Notebook)

## Files
- `dataset.csv` – Source dataset
- `mysql_quries_.sql` – SQL queries used for analysis
- `customer_behavoir_presentation.pbix` – Interactive Power BI dashboard
- `Untitled.ipynb` – Data analysis notebook

## Key Insights
- Customer segmentation
- Sales trends
- Purchase behavior analysis
- Interactive dashboard visualizations
